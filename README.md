# The Analogical Teacher 🎓🇰🇪

An interactive learning project that utilizes AI to translate complex technical concepts into relatable, everyday analogies from Nairobi daily life and local industries.

## 📋 Project Overview

The goal of **The Analogical Teacher** is to bridge the gap between abstract computer science theory and practical, local understanding. By forcing the AI to "think local," this project facilitates deeper retention through **The Socratic Method** and **Active Recall**.

## 🚀 Learning Goals

* **1-on-1 Learning:** Leveraging AI as a personalized tutor.
* **Active Recall:** Testing knowledge through AI-generated quizzes.
* **Localization:** Making technology accessible by using cultural context (e.g., Matatus, M-Pesa, Estate management).
* **Technical Communication:** Practicing the ability to explain high-level concepts to beginners.

## 🧠 Concepts Explored

1.  **Blockchain Technology**
    * *Analogy:* The "M-Pesa Ledger" of Muthurwa Market.
    * *Core Lesson:* Decentralization and Immutability.
2.  **Neural Networks (Machine Learning)**
    * *Analogy:* The Matatu Driver’s "Route Sense."
    * *Core Lesson:* Pattern recognition and Weight Adjustment (Loss/Error).
3.  **Cloud Computing**
    * *Analogy:* The Estate Water Tank System.
    * *Core Lesson:* Scalability and Pay-as-you-go resources.

## 🛠️ Structure of the Deliverable

Each concept in this project follows a strict 4-stage evaluation:
1.  **The Prompt:** The specific "Prompt Engineering" used to guide the AI.
2.  **The Output:** The local analogy, visual description, and "10-year-old" version.
3.  **Active Recall:** A log of the quiz interaction and AI feedback.
4.  **Evaluation:** A critical rating of the AI's accuracy, memorability, and accessibility.

## 💻 Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Slate & Electric Blue theme).
* **AI Engine:** Gemini.
* **Workflow:** Windows CMD for Git version control.
